Conception d'une plateforme e-commerce de reconditionnement technologique — LOOP — dans le cadre d'un projet de groupe (SAÉ S2.05). Le dossier couvre l'analyse des besoins, la modélisation d'une base de données relationnelle (40 tables, 7 modules), la définition des fonctionnalités front-office et back-office, l'arborescence du site et les maquettes des 49 écrans.
